# 03: 独立三态管理与恢复全部

**What to build:** 用户为每个已选 App 独立指定正常、上锁、隐藏，保存请求状态并在重开后继续管理，最后一键撤销本工具全部限制并退出。

**Blocked by:** 01 / 个人授权与单 App 隐藏恢复。

**Status:** ready-for-agent

- [ ] A 状态切换不改变 B；上锁保留图标并显示系统 shield。
- [ ] 取消选择自动释放对应限制，不清除其他工具限制。
- [ ] 重开保留选择和请求状态，前后台不自动重新施加。
- [ ] 恢复全部优先解除限制，保存失败提示重试并阻止后续编辑。
- [ ] 行为测试覆盖隔离、持久化、损坏数据及限制数量。
