# 01 · 重进管理页并恢复

**What to build**

存在旧隐藏记录时，用户仍能打开计算器、进入管理页、导出日志并尝试恢复。

**Blocked by**

None (can start immediately).

**Status** ready-for-agent

- [ ] 保存隐藏后退出、从后台回到前台和冷启动均可再次用 PIN 进入管理页。
- [ ] 加载旧记录、重进管理页和编辑备注均不重施加策略。
- [ ] 系统调用挂起时，退出和日志导出仍可操作，界面显示等待并防止并发提交。
- [ ] 旧隐藏记录能逐个恢复，恢复全部后回到计算器，其他工具的限制由其自身管理。
