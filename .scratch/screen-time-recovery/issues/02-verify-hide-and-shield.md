# 02 · 真机分测隐藏、上锁和恢复

**What to build**

在 iOS 16.3 上，以同一个 App 验证上锁是否显示限制页、隐藏是否移除图标，以及恢复是否解除本工具的限制。

**Blocked by**

01 · 重进管理页并恢复。

**Status** ready-for-agent

- [ ] 独立记录授权、shield 写入、blocked 写入的调用结果及桌面、搜索、实际启动的观察结果。
- [ ] 先验证纯上锁和恢复，再验证隐藏和恢复，区分图标可见但被限制与完全可启动。
- [ ] 若 token 隐藏仍失败，使用受控实验验证公开 Bundle ID 初始化路径和安装身份的影响；根据结果更新实现和 UI。
- [ ] 恢复单项只移除本工具对该条目的限制，其他条目保持原请求。

1.0.5 已生成 IPA 和匹配符号。核心测试已验证策略隔离。桌面、搜索、系统限制页、实际启动与恢复由 iOS 16.3 真机独立复验。Bundle ID 对照在 token 路径仍失败时进行。
